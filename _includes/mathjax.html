{%- comment -%} MathJax 3, loaded only on pages that actually contain math (see _layouts/article.html). Two delimiter families must both be enabled: - \[ ... \] and \( ... \) : kramdown 2.4's default math_engine: mathjax already rewrites $$ ... $$ blocks/spans into these before the HTML is emitted, so MathJax has to recognise them. - $ ... $ and $$ ... $$ : kramdown does NOT parse single-$ inline math, so the delimiters survive into the HTML untouched and the browser has to handle them. Escape a literal dollar in prose as \$ (processEscapes turns it into $). {%- endcomment -%}
